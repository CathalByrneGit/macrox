# Show validation results for all tables

Prints a summary of every
[`validate_table()`](https://cathalbyrnegit.github.io/macrox/reference/validate_table.md)
result stored in the session.

## Usage

``` r
show_validations(sess)
```

## Arguments

- sess:

  A `macrox_session` object.

## Value

`sess` invisibly. \# not recorded
