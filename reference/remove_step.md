# Remove a recorded step by index

Remove a recorded step by index

## Usage

``` r
remove_step(sess, index)
```

## Arguments

- sess:

  A `macrox_session` object.

- index:

  Integer index of the step to remove (see
  [`show_steps()`](https://cathalbyrnegit.github.io/macrox/reference/show_steps.md)).

## Value

`sess` invisibly.
